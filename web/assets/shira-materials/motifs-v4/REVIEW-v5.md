# 希拉 v5：立绘宽度优先

问题：v4 保留纵向堆叠，把视口高度扣掉桌宠、背包等，再除以 1.618 反算立绘宽度。这导致黄金比例形式成立但实际展示过窄。

本轮：右栏按窗口宽度分配，立绘与桌宠各自一列；背包在立绘下方。主列使用剩余宽度，不再被下方桌宠高度挤压，仍保留 1:1.618。短窗口允许右栏局部滚动，不能用裁切掩盖控件超出。

按 CSS 计算、不含滚动条：1190 宽时立绘 242px；1366 宽时约 282px；1920 宽时 332px。聊天区在这些尺寸仍至少保留 500px。桌宠展示空间约 170–210px。

装饰：聊天区撤下独立魅魔印，集中到桌宠侧位；魅魔印、翼心上下分区，单片花瓣安排在侧边与间隔位置。沿用已有素材，不为增加数量生图。

本轮浏览器连接仍失败，以上为代码与尺寸预算审查，不是实屏视觉验收。需实际检查右侧构图、短窗口滚动、立绘翻卡、背包点击与桌宠菜单。
