# 希拉视觉整合 v3 / 2026-09-14

## 改前问题 → 本轮处理

1. 五片花瓣作为整段图片展示 → 从原 alpha 空白间隔切分出五个独立 PNG，逐一定位；只放三片，两片备用，不挤占桌宠空间。
2. 立绘纵向占比过大、桌宠 128px → 立绘容器最高 430px，底部给桌宠预留真实空间；桌宠随高度为 170–254px，短窗口降到 158px，不改动作状态机。
3. 多个边角纹样叠加 → 单一新框体采用九宫格边框，固定 24px 角部，直边延展；透明中心不绘制，不叠旧卷纹。
4. 冷灰色与花瓣脱节 → 黑莓底、酒红表面、玫瑰色按钮与线条；保留可读性和手动主题优先。
5. 页面切换无回程 → 顶部返回按钮记录实际模块访问顺序，连续返回不会反复跳转；没有上一页时隐藏。刷新后从非聊天页开始则允许回到聊天。

## 文件

- shira-romance.css：本轮配色、比例、装饰的独立样式层。
- panel-history.js / panel-history.test.cjs：会话内模块返回记录及单元测试。
- app.js / index.html：按钮及模块接入。
- shira-materials/accents-v3：五片花瓣和框体，旧资源未删除。

## 调色

在 shira-romance.css 修改主题 token。花瓣可通过 `--shira-flower-filter`、`--shira-flower-opacity` 调整。
新框体是原色 PNG，通过 `--shira-frame` 更换资源，不能声称由 `--shira-ornament-color` 控制其颜色。

## 素材制作

花瓣来自 exec-ca59e74f-4959-4ab4-acb0-c190757dbdf5.png，按用户要求以 alpha 间隔逐片裁剪，并保留透明通道。
新框体由内置 imagegen 生成，源文件 exec-1caaec35-65b4-4f23-b869-5d86cf9966ca.png。
提示词：透明中心的正方形 UI 面板框；平面灰玫瑰线稿，无金属光泽、无阴影，细直边和克制的卷尾心形角；四角适合九宫格缩放，不生成整张界面。

## 验证边界

素材 alpha、JS 语法、返回记录单元测试和本地 HTTP 可以验证。
实跑：14 项主题、返回记录、接线和新配色对比度测试通过。最终采用 PNG，避免本地服务的 WebP 通用 MIME 类型。
本轮浏览器控制连接失败（重新初始化后仍失败）；无法取得改后实屏截图。
因此本轮不是“视觉审核通过”，还需要实屏检查 1366×768、1920×1080 的配色、边框接缝、立绘翻卡、桌宠菜单、返回按钮和长消息可读性。
