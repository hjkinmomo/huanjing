# 视觉小说场景素材 · 第一组

四张独立横版背景：暮色商店街、礼品店、书店、咖啡店。使用内置 image_gen 生成；完整提示词在 manifest.json。

用途：后续逛街与视觉小说的场景候选。不是整张 UI，不含固定角色。角色立绘、场景文字、选项、返回键和聊天框由程序独立叠加，不烧进背景。

视觉检查：四张暖木色/蓝色暮光氛围协调；中景可用于立绘，底部仍需独立对话框保证可读性。街景招牌与书脊有少量生成字迹，不作为可读文字或交互入口。柜台上的物品是环境陈设，不代表已购商品或库存。

限制：图片是完整不透明背景，不是可独立点选的商品抠图；尚未验证与三名角色立绘、不同窗口尺寸的实际叠加效果。没有冒充后续玩法已经实现。

接入建议：使用声明式资源映射选择背景，角色层与对话层分别渲染。第一次进入显式加载当前场景，只预加载相邻场景；不要一次加载全部原始 PNG。后台场景不要铺进聊天、设置等所有页面。减少动效时切换背景不播放过渡动画。

保存：原生成文件保留；项目仅新增 stories 目录与版本化 v1 文件，不替换旧图片，不改用户数据。
