# 幻境 · Huanjing

一个在 Windows 本机运行、通过浏览器使用的酒馆式 AI 角色扮演与生活模拟项目。和角色聊天，也在同一个城市里生活：出门、送礼、点外卖、发朋友圈，或从整局存档继续自己的故事。

`角色扮演` · `酒馆风格聊天` · `AI 陪伴` · `生活模拟` · `虚拟手机` · `互动叙事`

## 可以做什么

- **角色与记忆**：13 位内置角色，也可添加新角色；各自保留对话与记忆。
- **身份与故事存档**：选择用户身份，开始新一局，或恢复整局角色关系与世界进度。
- **虚拟手机**：微聊、群聊、朋友圈、购物、外卖、背包、日程与账本。
- **城市与出行**：查看场景平面图和人物位置，在房间间移动，选择步行、公交或打车出行。
- **日常互动**：送礼、角色事件与小游戏，让故事在聊天之外继续。
- **周历与日程**：夏城日历、节假日与角色每周安排；可单独配置规划模型，手动修改日程，或在聊天中商量后确认约定。
- **时间与位置连续**：重新打开时推进故事时间；角色接受室内邀请后更新具体房间，并在聊天显示到达回执。

## 快速开始

需要 Windows x64 和 Git。在 PowerShell 中执行：

```powershell
git clone https://github.com/hjkinmomo/huanjing.git
cd huanjing
.\start-project5.ps1
```

打开启动输出中的本机网页地址。已附带 Python 运行环境，正常使用无需安装 Node.js。

1. 在设置中填写自己的模型接口、模型名称和 API Key，验证并保存。
2. 点击「开始游戏」，选择一位角色，再创建新对话。
3. 第一次开局时选择用户身份与起点，即可开始故事。

顶部「周历与日程」可查看、生成本周计划。「我们去卧室吧」这类同场景邀请会根据角色的实际回复判定是否移动；反问后的确认只接续当前邀请，不会从旧聊天翻出过期目的地。普通聊天不增加位置判断调用，每个有效移动相关回复最多额外一次，使用当前角色配置的模型。

查看服务状态或停止服务：

```powershell
.\status-project5.ps1
.\stop-project5.ps1
```

## 开发与版本说明

修改前端时，在 `frontend` 目录执行 `npm ci` 和 `npm run build`；卡片构建命令为 `node tools/build-role-card.cjs`。

本仓库为普通模式公开版，已移除特殊模式专属人格资料和场景。仓库不附带私人聊天、提取记忆、用户存档、API Key、旧指南、历史测试报告或备份。运行时在本机创建 `data` 和 `knowledge` 目录；使用模型接口时，会向所配置的服务发送生成所需的上下文。

素材和第三方运行库保留各自附带的许可说明，本仓库不另行授予第三方素材许可。
